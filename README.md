# 🎟️ E-Ticketing Platform

**Language:** Java  
**Type:** Console application (interactive menu)  
**Author:** Irina Moise

---

## 📘 Overview

This project implements a **Java-based e-ticketing platform** with an **interactive console menu** that allows users to manage **events, venues, artists, and tickets**.  
It demonstrates **strong Object-Oriented Programming (OOP)** principles and a modular, extensible architecture.

---

## ⚙️ Features

- Interactive menu for managing events, venues, artists, and tickets  
- Create, edit, delete, and search for events  
- Reserve, purchase, and cancel tickets  
- Basic seat and capacity management  
- Simple reporting (available seats, sold tickets, etc.)

---

## 🧠 OOP Principles Applied

- **Encapsulation:** each class hides its data and exposes clear methods  
- **Abstraction:** core entities modeled as `Event`, `Venue`, `Artist`, `Ticket`  
- **Inheritance & Polymorphism:** shared logic via base classes and interfaces  
- **Composition over Inheritance:** objects are built from smaller components  
- **Single Responsibility Principle (SRP):** each class handles one concern  
- **Open/Closed Principle (OCP):** easily extend features without modifying core code
